# Bob Session Summaries

Place screenshots of IBM Bob task session summaries here.

Each session summary screenshot should be named by date, e.g.:
- 2026-10-21-session.png
- 2026-10-22-session.png
- 2026-10-25-session.png

## How to export from Bob IDE

1. In Bob IDE, open the task panel
2. Click the session summary icon (clock/history icon)
3. Screenshot or export the summary
4. Save here with the date as filename
