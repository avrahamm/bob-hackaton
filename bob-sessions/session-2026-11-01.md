No — the `.PF` suffix on the **local filename** is purely a developer convention for your PC/laptop to signal "this is a DDS Physical File source". IBM i itself does not use file extensions anywhere.

Here's how the naming works:

## IBM i object naming — no extensions

On IBM i, objects live in a library and have:
- An **object name** (up to 10 characters)
- An **object type** (e.g. `*FILE`)
- A **file attribute** (e.g. `PF-DTA` for physical data file, `LF` for logical file)

The object type and attribute *are* the "extension" — stored as metadata, never in the name itself.

## What the three options mean

| Option | What it creates on IBM i | Correct? |
|---|---|---|
| `CUSTPF` | Object named `CUSTPF` of type `*FILE` (PF-DTA) | ✅ **This is the IBM i convention** |
| `CUST.PF` | **Invalid** — IBM i object names cannot contain a dot | ❌ |
| `CUSTPF.PF` | **Invalid** — same reason, and also > 10 chars without the dot | ❌ |

## The `.pf` on your PC file

[`ibmi/dds/CUSTPF.pf`](ibmi/dds/CUSTPF.pf) — the `.pf` here is just your local OS filename extension so your editor and directory listing can tell it apart from RPG or SQL files. It has no meaning to IBM i.

## When you upload via IBM i extension (Bob IDE / VS Code)

The IBM i extension maps your local file to an IBM i source member. It uses the **filename without the extension** as the member name, and the **extension** as the source type:

| Local file | Member name on IBM i | Source type |
|---|---|---|
| `CUSTPF.pf` | `CUSTPF` | `PF` |
| `POLICYPF.pf` | `POLICYPF` | `PF` |
| `CLAIML1.lf` | `CLAIML1` | `LF` |

So the upload will create member `CUSTPF` with type `PF` inside whichever source PF you target (e.g. `ESH101/QDDSSRC`). Then `CRTPF OBJ(ESH101/CUSTPF) SRCFILE(ESH101/QDDSSRC)` creates the object named `CUSTPF`. That is the name your SQL and RPG code use.

**Bottom line:** upload as `CUSTPF` — the name in your DDS source comment is exactly right.

// POLSRV -- Insurance policy lookup (legacy green-screen program)
// Library: ESH101
//
// This program represents the BEFORE state: native RPG file I/O
// (CHAIN + READE) reading DDS physical/logical files directly.
// An insurance agent would use this from a 5250 terminal to look
// up a policy and its claims.
//
// Compare with the AFTER state:
//   FastAPI → JT400 JDBC → SQL stored procedures (LIST_POLICIES,
//   GET_POLICY, LIST_CLAIMS) → same physical files → modern web UI.
//
// Files used:
//   POLSRVD  -- display file (DSPF) defined in ibmi/dds/POLSRVD.dspf
//   POLICYPF -- policy physical file  (key: POLID)
//   CUSTPF   -- customer physical file (key: CUSTID)
//   CLAIMLF1 -- claims logical file   (key: POLID + CLAIMNO)
//
// Compile (after POLSRVD is compiled):
//   CRTBNDRPG PGM(ESH101/POLSRV) SRCFILE(ESH101/QRPGLESRC) +
//             SRCMBR(POLSRV) OPTION(*EVENTF) DFTACTGRP(*NO)
//
// Run:
//   CALL ESH101/POLSRV
// %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

// ------------------------------------------------------------------
// File declarations
// ------------------------------------------------------------------
Dcl-F POLSRVD  WorkStn SFile(CLMSFL : RRN);
Dcl-F POLICYPF Disk    Usage(*Input) Keyed;
Dcl-F CUSTPF   Disk    Usage(*Input) Keyed;
Dcl-F CLAIMLF1 Disk    Usage(*Input) Keyed;

// ------------------------------------------------------------------
// Work variables
// ------------------------------------------------------------------
Dcl-S RRN        Uns(5)  Inz(0);
Dcl-S WkPolId    Packed(8:0);
Dcl-S WkCustId   Packed(7:0);
Dcl-S Found      Ind;
Dcl-S HasClaims  Ind;

// Status label lookup
Dcl-S WkStatus   Char(10);
Dcl-S WkClaimSts Char(10);

// ------------------------------------------------------------------
// Main procedure
// ------------------------------------------------------------------
Dcl-Proc Main;
  Dou *In03;                           // loop until F3=Exit

    // Show search screen
    ERRMSG = *Blanks;
    Write SEARCH;
    Exfmt SEARCH;

    If *In03;                          // F3 pressed
      Leave;
    EndIf;

    If SRCHID = 0;
      ERRMSG = 'Please enter a Policy ID.';
      Iter;
    EndIf;

    WkPolId = SRCHID;
    Exsr LoadPolicy;

  EndDo;

  *InLR = *On;
End-Proc;

// ------------------------------------------------------------------
// LoadPolicy -- CHAIN to POLICYPF, build display, load claims SFL
// ------------------------------------------------------------------
Dcl-Proc LoadPolicy;

  // CHAIN to POLICYPF by POLID
  Chain (WkPolId) POLREC;
  Found = %Found(POLICYPF);

  If Not Found;
    ERRMSG = 'Policy ID ' + %Char(WkPolId) + ' not found.';
    Return;
  EndIf;

  // Populate policy header display fields
  DPOLID   = POLID;
  DPOLTYPE = POLTYPE;
  DPREMIUM = PREMIUM;

  // Expand STATUS code to label
  Select;
    When STATUS = 'A';
      DSTATUS = 'Active';
    When STATUS = 'E';
      DSTATUS = 'Expired';
    When STATUS = 'C';
      DSTATUS = 'Cancelled';
    Other;
      DSTATUS = STATUS;
  EndSl;

  // Format dates (stored as ISO date fields, display as YYYY-MM-DD)
  DSTARTDT = %Char(STARTDT : *ISO);
  DENDDT   = %Char(ENDDT   : *ISO);

  // CHAIN to CUSTPF to get customer name
  WkCustId = CUSTID;
  Chain (WkCustId) CUSTREC;
  If %Found(CUSTPF);
    DCUSTNAME = CUSTNAME;
  Else;
    DCUSTNAME = 'Unknown customer';
  EndIf;

  // Load claims into subfile
  *In90 = *On;                         // indicator 90 = clear subfile
  Write CLMCTL;
  *In90 = *Off;

  RRN = 0;
  SetLL (WkPolId) CLAIMREC;           // position to first claim for this policy

  Dou %EOF(CLAIMLF1);
    ReadE (WkPolId) CLAIMREC;
    If %EOF(CLAIMLF1);
      Leave;
    EndIf;

    RRN += 1;
    SCLAIMNO   = CLAIMNO;
    SCLAIMDT   = %Char(CLAIMDT : *ISO);
    SCLAIMTYPE = CLAIMTYPE;
    SAMOUNT    = AMOUNT;
    SDESCR     = %SubSt(DESCR : 1 : 30); // truncate to 30 for display

    Select;
      When CLAIMSTS = 'O';
        SCLAIMSTS = 'Open';
      When CLAIMSTS = 'A';
        SCLAIMSTS = 'Approved';
      When CLAIMSTS = 'R';
        SCLAIMSTS = 'Rejected';
      When CLAIMSTS = 'P';
        SCLAIMSTS = 'Paid';
      Other;
        SCLAIMSTS = CLAIMSTS;
    EndSl;

    Write CLMSFL;                      // write subfile record
  EndDo;

  HasClaims = (RRN > 0);

  // Show policy detail + claims subfile
  Dou *In03 Or *In12;                  // loop until F3=Exit or F12=New Search
    Write POLDET;
    Exfmt CLMCTL;
  EndDo;

  *In12 = *Off;                        // reset F12 so outer loop continues

End-Proc;

Main();

| Usage | Valid data types | Notes |
|---|---|---|
